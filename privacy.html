Privacy Policy

Last updated: September 13, 2026

This Privacy Policy explains how Oura Exporter handles information when you connect an Oura account and use the application.

Information accessed

Oura Exporter may request access, with your authorization, to data made available through the Oura API. Depending on the permissions you grant, this may include profile information and health or wellness information such as sleep, readiness, activity, heart-rate, workout, session, tag, and blood-oxygen data.

How information is used

The information is used only to provide the application's functions, including retrieving your Oura data, storing it locally, synchronizing updates, displaying import information, and creating personal data exports such as CSV or JSON files.

OAuth credentials and tokens

Oura Exporter uses OAuth authorization to access Oura data. OAuth access and refresh tokens may be stored locally on the computer running the application so that authorized API access can continue. Your Oura account password is not collected or stored by Oura Exporter.

Storage

The application is designed as a local application. Imported Oura data and authentication tokens are stored locally on the user's computer. The application does not intentionally transmit imported Oura data to an external application server operated by Oura Exporter.

Sharing and sale of data

Oura Exporter does not sell personal information or Oura data. The application does not use Oura data for advertising and does not intentionally share imported Oura data with third parties. Data may leave the local computer only when the user independently exports, copies, backs up, or otherwise transfers it.

Data retention and deletion

Locally imported information remains on the user's computer until the user deletes it. Users can remove locally stored data by deleting the application's local database and generated export files. Users can also disconnect the application and revoke its authorization through the relevant Oura account controls.

Security

Reasonable measures are used to keep credentials and imported information local to the application. However, no computer system or storage method can be guaranteed to be completely secure. Users are responsible for protecting access to the computer on which the application is installed.

Third-party service

Oura Exporter relies on the Oura API to retrieve information authorized by the user. Oura's own services and handling of information are governed by Oura's policies and terms.

Changes to this policy

This Privacy Policy may be updated if the application's functionality or data-handling practices change. The revision date at the top of this page indicates the latest version.

Contact

For privacy questions concerning Oura Exporter, contact the application operator using the contact information provided with the application or its public project page.
