Oura Exporter

Oura Exporter is a small personal application for accessing and exporting health and wellness data from the Oura API.

The application lets an authorized user connect an Oura account using OAuth, retrieve selected Oura data, store it locally, and export it for personal analysis in formats such as CSV and JSON.

Oura Exporter is an independent application and is not affiliated with, endorsed by, or sponsored by Oura Health Oy.

Data handling

The application is designed to keep imported Oura data on the user's own computer. It does not sell Oura data or use it for advertising.
